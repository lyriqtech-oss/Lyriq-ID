# Lyriq ID

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Delegated implementation: dependency-free Node.js server and browser client for the first runnable foundation. Native mobile and standards-compliant OIDC remain separate delivery milestones.

## Users
People and organizations using Lyriq products who need one identity and visible control over access.

## Product Purpose
Central identity for Lyriq services, beginning with account access and a security center.

## Capabilities and Constraints
Passkeys are preferred; password is an optional fallback. Only first-party Lyriq services may be clients. Critical actions require explicit approval. No raw biometrics or service-role credentials in browser code. The supplied specification defines later phases; a screen is not evidence of a working security control.

## Brand Commitments
Use the supplied fingerprint mark and dark silver, ice-blue, blue visual direction.

## Evidence on Hand
Four user-provided visual references and the detailed product specification in the attached text files. The GitHub repository was empty when work began.

## Product Principles
Strong authentication, clear account control, least privilege, and honest security status.
